# Lista de tareas del proyecto

> **Etapa actual:** levantamiento de información y medidas.  
> **Objetivo:** reunir datos suficientes para dibujar el puesto actual a escala.  
> Marca las casillas solo cuando la tarea esté realmente terminada.

## 1. Preparar la visita

- [ ] Conseguir una cinta métrica (preferentemente de 5 m o más).
- [ ] Llevar el teléfono con batería para fotografiar.
- [ ] Llevar papel o usar la [plantilla de levantamiento de medidas](../mediciones/plantilla-levantamiento.md).
- [ ] Usar centímetros como unidad y anotar cada dimensión inmediatamente.
- [ ] Pedir permiso antes de fotografiar a otras personas; evitar captar rostros de clientes.

## 2. Medir el espacio municipal

- [ ] Medir el largo total disponible.
- [ ] Medir el ancho total disponible.
- [ ] Registrar límites y obstáculos.
- [ ] Identificar desniveles, pendiente y tipo de suelo.
- [ ] Identificar por dónde llegan y se retiran los clientes.
- [ ] Medir el espacio que ocupan la banca, mesa, carretilla y asiento.
- [ ] Registrar las separaciones entre elementos.
- [ ] Consultar si existen reglas municipales sobre dimensiones, ubicación o mobiliario.

## 3. Medir la banca y la mesa

- [ ] Medir largo, ancho y altura de la banca.
- [ ] Registrar cuántas personas pueden sentarse.
- [ ] Medir largo, ancho y altura de la mesa.
- [ ] Fotografiar su orientación y relación con el flujo de clientes.
- [ ] Confirmar si pueden moverse o deben permanecer donde están.

## 4. Medir las cuatro ollas

Crear un registro separado para cada una: grande 1, grande 2, pequeña 1 y pequeña 2.

- [ ] Medir diámetro de la base.
- [ ] Medir diámetro superior.
- [ ] Medir altura sin tapa.
- [ ] Medir altura total con tapa.
- [ ] Registrar asas, salientes y orientación.
- [ ] Registrar espacio necesario para abrir y retirar la tapa.
- [ ] Registrar peso vacío.
- [ ] Estimar peso lleno mediante un método seguro.
- [ ] Tomar una foto con la cinta métrica visible.

## 5. Medir la carretilla actual

- [ ] Medir largo total, incluidos los mangos.
- [ ] Medir ancho total.
- [ ] Medir altura de la plataforma.
- [ ] Medir altura de los mangos.
- [ ] Medir diámetro y ancho de las ruedas.
- [ ] Registrar cantidad y ubicación de ruedas.
- [ ] Medir las dos tablillas y documentar cómo sostienen las ollas.
- [ ] Fotografiar desde arriba, frente, atrás y ambos lados.
- [ ] Observar si se inclina, bambolea o cuesta girarla/detenerla.

## 6. Registrar baldes, utensilios y asiento

- [ ] Medir diámetro y altura del balde de platos descartables.
- [ ] Confirmar si contiene aproximadamente 50 platos.
- [ ] Medir el segundo balde.
- [ ] Registrar cuánta agua transporta.
- [ ] Aclarar qué objetos se lavan exactamente.
- [ ] Identificar dónde se recoge o elimina el agua usada.
- [ ] Hacer inventario de cucharas, cucharones, servilletas, bolsas y otros utensilios.
- [ ] Medir alto, ancho y profundidad del asiento.
- [ ] Registrar espacio para piernas y pies.

## 7. Registrar el recorrido de transporte

- [ ] Anotar dónde se carga la carretilla.
- [ ] Anotar dónde comienza y termina el recorrido.
- [ ] Estimar o medir la distancia.
- [ ] Fotografiar pendientes, baches, piedras, veredas, escalones y giros.
- [ ] Confirmar si las cuatro ollas viajan llenas o parcialmente llenas.
- [ ] Registrar si otra persona ayuda.
- [ ] Observar cómo se estaciona e inmoviliza la carretilla.

## 8. Observar el trabajo de mamá

- [ ] Fotografiar el puesto antes de iniciar la venta.
- [ ] Fotografiar la disposición durante la atención.
- [ ] Fotografiar cómo queda al final de la jornada.
- [ ] Observar dónde guarda cada implemento.
- [ ] Identificar qué objetos busca con mayor frecuencia.
- [ ] Observar cómo sirve una porción y qué movimientos repite.
- [ ] Preguntarle qué le resulta más incómodo.
- [ ] Preguntarle qué cambio le facilitaría más el trabajo.
- [ ] Registrar cómo le afecta el frío en los pies.

## 9. Preparar el diseño

- [ ] Completar la plantilla de medidas.
- [ ] Revisar que no falten dimensiones críticas.
- [ ] Ordenar las fotografías en una carpeta.
- [ ] Dibujar un plano 2D del espacio a escala.
- [ ] Verificar que banca, mesa, carretilla y asiento encajen.
- [ ] Añadir el espacio de circulación y de trabajo.
- [ ] Definir requisitos de la nueva carretilla.
- [ ] Comparar al menos dos distribuciones posibles para las cuatro ollas.
- [ ] Comenzar el modelo 3D en Blender después de validar el plano 2D.

## Entregable de esta etapa

- [ ] Medidas del espacio y mobiliario.
- [ ] Medidas de las cuatro ollas.
- [ ] Medidas de carretilla, baldes y asiento.
- [ ] Fotografías del puesto y del recorrido.
- [ ] Registro del proceso de transporte.
- [ ] Aclaración del uso del segundo balde.

**La etapa se considera terminada cuando los datos permiten dibujar el puesto a escala sin inventar dimensiones.**
